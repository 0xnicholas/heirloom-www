# Hero 文案与措辞准则

定自 [#3](https://github.com/0xnicholas/heirloom-www/issues/3) 会诊，约束全站现有与未来文案。

**Hero 定稿**

- Headline: "Your enterprise domain model, as code."
- Subhead: "Heirloom is an open-source, self-hosted ontology layer: data, actions, logic, and security — defined once in TypeScript."

**措辞准则七条**

1. 术语对齐 `heirloom-pro/CONTEXT.md`：object type / link / action / property 用原词；四支柱固定写法 "data, actions, logic, and security"（顺序固定）。
2. ontology 小写、作普通名词（"an ontology layer" / "your ontology"），不大写不神秘化。
3. 禁用词：no-code / low-code / AI-powered / enterprise-grade / seamless / next-generation / single source of truth；不出现任何竞品名（ADR-0002）。
4. 声称纪律：只描述 spec 冻结的 v1 语义；v2 特性（GraphQL、副作用编排）除非标 "roadmap" 否则不提；不用截图或措辞暗示存在 UI。
5. 人称语态：对读者用 "your"，产品主语用 "Heirloom"，主动语态短句。
6. 代码示例承 [#2](https://github.com/0xnicholas/heirloom-www/issues/2) 落地注意：displayName 与注释英译，对照 `docs/research/code-sample.md` 核对语法真实性。
7. 书写规范："open-source" / "self-hosted" 作定语带连字符；许可证写 Apache-2.0。
