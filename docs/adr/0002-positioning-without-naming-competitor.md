# 定位叙事不点名竞品

全站不出现 Palantir / Foundry 等任何竞品名。Headline 立「企业领域模型」品类并以 as code 收尾；对标认知只靠 ontology、四支柱等术语暗示，懂的人自会会心。

取舍：放弃 "open-source Foundry alternative" 的认知捷径与搜索流量，换独立产品身份与零商标依附——不点名的独立叙事与「重造轮子共鸣」的目标读者第一反应（「每个项目都在重造的这一层，有人做成了产品」）一致。

相关表述纪律：项目尚在 spec 阶段只在页脚提（首屏不套免责声明），「无 UI」在后段交代（Hero 不承担过滤器职责）。定自 [#3](https://github.com/0xnicholas/heirloom-www/issues/3) 会诊。

## Considered Options

- **副标题/首屏点名 Foundry**：认知锚定最快、吃搜索流量，但整页身份依附 Palantir，且有商标风险。
- **页面后段设对照块**：Hero 干净但等于把定位问题推后，与不点名决策一起被否。
